# Churrascaria Novilha de Ouro

Landing page responsiva feita em HTML, CSS e JavaScript puro.

## Conteúdo
- Identidade visual premium em preto e dourado
- Hero com destaque para buffet à vontade
- Preço: R$ 39,90 por pessoa, com bebidas inclusas
- Apresentação da casa, buffet e opções disponíveis
- Formas de pagamento
- Endereço, horário e mapa
- Links de WhatsApp e navegação mobile
- Animações leves com suporte a `prefers-reduced-motion`
